推し活テンプレメーカーのモニター版です。
有料版と同じく、4枚・3枚・1枚の写真テンプレに対応しています。
文字入れはなく、写真配置とPNG保存だけに絞っています。

モニター版の違い:
- プレビュー画面に「感想フォーム」欄があります
- 感想フォームURLが未設定の間は、PNG保存ボタンを押せません
- Googleフォームに回答後、「感想フォームに回答しました」にチェックすると保存できます

注意:
このアプリはGitHub Pagesの静的サイトです。
アプリ内だけで感想フォームを作っても、回答データは蓄積されません。
回答を残すにはGoogleフォームなどの保存先が必要です。

GoogleフォームURLの設定場所:
index.html の `FEEDBACK_FORM_URL` に、GoogleフォームのURLを入れます。

例:
const FEEDBACK_FORM_URL = 'https://forms.gle/xxxxxxxxxxxx';

厳密に「本当に回答済みか」を判定するには、Google Apps Scriptなどの追加連携が必要です。
現状は「フォームを開く -> 回答しましたにチェック -> 保存解放」の簡易版です。
